# 广告物料生产图生成工作台 Demo

这是一个广告物料 / 美陈生产图纸插件 demo，用于验证从效果图或甲方尺寸标注图生成生产图纸的工作流。

## 快速开始

[📖 打开 Demo](index.html)

## 当前能力

- 普通效果图 / 渲染图输入
- 甲方尺寸效果图 / 3D 标注图输入
- 统一参数引擎
- 正面尺寸图、平面图、侧视图、刀版展开图
- 图纸放大查看
- AI 微调助手
- PDF / SVG / DXF / AI-CDR 导出 demo
- 门头 / 墙面装置、堆头、美陈装置等物料类型示意

## 不包含

当前阶段暂不包含 CAD、DWG、3D 建模、VI 创意生成。

## 使用方式

直接打开 `index.html` 即可查看 demo。
