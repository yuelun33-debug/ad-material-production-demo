# Ad Material Production Demo

一个面向广告物料、美陈、商超陈列、堆头、展台、陈列架等设计公司的生产图生成工作台 demo。

## Demo 内容

- 上传原始效果图 / 参考图
- 输入整体宽度、高度、深度、材料、厚度、出血等参数
- 生成正面尺寸图、平面图、侧视图和刀版展开图
- 展示 CUT / SLOT / HOLE / BLEED / SAFE / DIM 等基础生产线型
- 提供 PDF / SVG / DXF / AI / CDR 兼容文件的导出方向展示

## 使用方式

直接打开 `index.html` 即可预览。

## 当前阶段

这是一个前端概念 demo，用来表达产品方向：把设计师已有的效果图或结构草图，转化为工厂能看懂的尺寸图、刀版图和基础矢量生产文件。
